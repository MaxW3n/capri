Check my Mac

This browser appears to be on a device other than a Mac. You can use the demo here or check a Mac below.

On the Mac you’ll use, open Apple menu → About This Mac. Check each item that matches.

For free space, open System Settings → General → Storage.

Confirm all four before starting setup.

After unzipping Capri, you can also check in Terminal before starting the model: bash ~/Downloads/capri-main/start.sh --check

  1. Install Python 3.13

    Download the Python 3.13 installer for macOS and open it. Use the installer’s default options.

    Get Python 3.13 ↗

  2. Get Capri from GitHub

    Open the public repo and choose Code → Download ZIP. Unzip it in Downloads and keep the folder named capri-main.

    Open Capri on GitHub ↗

  3. Start her

    Open Terminal (find it using Spotlight), paste this command and press Return:

    bash ~/Downloads/capri-main/start.sh

    The first launch sets up Capri’s libraries and downloads the model. Leave Terminal open. Wait until it says Capri is ready.

  4. Connect this page

    Click Connect local Capri below. If your browser asks for local or loopback network access, choose Allow.

    Switching between demo and local starts a new conversation. To stop the model later, press Control + C in Terminal.
