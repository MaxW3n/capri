YOUR MAC // YOUR MODEL

Run the real Capri.

Keep the 3D scene here. Your Mac generates the replies. No Ollama or paid API is needed.

Before you start Apple Silicon Mac · macOS 26.2+ · at least 24 GB memory (32 GB+ recommended) Allow 18 GB of free storage. The first model download is 16.1 GB.

  1. Install Python 3.13

    Download the Python 3.13 installer for macOS and open it. Use the installer’s default options.

    Get Python 3.13 ↗

  2. Download Capri

    Open the ZIP and keep the folder named capri-main in your Downloads folder.

    Download Capri ZIP ↓

  3. Start her

    Open Terminal (find it using Spotlight), paste this command and press Return:

    bash ~/Downloads/capri-main/start.sh

    The first launch sets up Capri’s libraries and downloads the model. Leave Terminal open. Wait until it says Capri is ready.

  4. Connect this page

    Click Connect local Capri below. If your browser asks for local or loopback network access, choose Allow.

    Switching between demo and local starts a new conversation. To stop the model later, press Control + C in Terminal.

Demo mode

No connection to your Mac has been requested. Connect only after starting Capri.

If access is blocked: open your browser’s Site settings for this page, allow local or loopback network access, then try again.

Some browsers cannot link an HTTPS website to a local server. You can still open Capri’s local chat after the server starts.
